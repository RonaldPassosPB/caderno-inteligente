=== operadores | 1 | dart | Operações matemáticas
--- lesson
Os operadores são os de sempre: `+`, `-`, `*`, `/` e `%` (resto). A diferença está na divisão:

```dart
print(7 / 2);    // 3.5  -> no Dart, / SEMPRE devolve double

print(7 % 2);    // 1
```

Para formatar casas decimais: `(10 / 3).toStringAsFixed(2)` devolve `'3.33'`.

=== listas | 1 | dart | Listas e métodos funcionais
--- lesson
A **List** é a coleção mais usada no Flutter. Toda lista de tela começa numa:

```dart
var notas = <double>[7.5, 8.0, 6.0];
notas.add(9.0);
notas.length;                        // 4
notas.first; notas.last;

notas.where((n) => n >= 7)           // filtra
notas.map((n) => n * 10)             // transforma
notas.reduce((a, b) => a + b)        // acumula: soma tudo
notas.any((n) => n < 5)              // algum menor que 5?
```

`where` e `map` devolvem um **Iterable**. Use `.toList()` quando precisar de uma List de novo. `(n) => n >= 7` é uma **função anônima** (lambda).
--- task
Com **notas = [7.5, 4.0, 9.5, 6.0, 8.0]**, mostre as linhas abaixo: as notas **≥ 7** (como lista), a **média** com 2 casas (usando reduce) e se **alguma** nota é menor que 5.
--- reqs
- Usa where com toList
- Usa reduce para somar
- Usa any
--- hints
- var altas = notas.where((n) => n >= 7).toList();
- var media = notas.reduce((a, b) => a + b) / notas.length;
--- starter
void main() {
  var notas = [7.5, 4.0, 9.5, 6.0, 8.0];

}
--- solution
void main() {
  var notas = [7.5, 4.0, 9.5, 6.0, 8.0];

  var altas = notas.where((n) => n >= 7).toList();
  var media = notas.reduce((a, b) => a + b) / notas.length;

  print('Notas altas: $altas');
  print('Média: ${media.toStringAsFixed(2)}');
  print('Alguma abaixo de 5? ${notas.any((n) => n < 5)}');
}

=== nullsafety | 2 | dart | Null safety
--- lesson
No Dart, uma variável **não pode ser null**, a menos que você diga com `?`. O compilador te protege do erro mais comum da programação:

```dart
String nome = 'Ana';      // nunca null
String? apelido;          // pode ser null (começa null)

apelido?.length           // ?.  se for null, devolve null em vez de quebrar
apelido ?? 'sem apelido'  // ??  valor padrão quando é null
apelido ??= 'Aninha';     // ??= atribui só se for null
apelido!                  // !   "confia, não é null" (evite: quebra se for)
```

Em Flutter, você vai ver muito isso com dados que ainda estão carregando.

- print('Tamanho: ${apelido?.length ?? 0}');  idade ??= 18;

=== heranca | 2 | dart | Herança, classes abstratas e interfaces
--- lesson
```dart
abstract class Forma {              // abstrata: não dá para instanciar
  String get nome;
  double area();                    // sem corpo: a filha é obrigada a implementar
  String descrever() => '$nome: ${area().toStringAsFixed(2)}';
}

class Quadrado extends Forma {      // extends = herda (inclusive descrever)
  final double lado;
  Quadrado(this.lado);
  @override String get nome => 'Quadrado';
  @override double area() => lado * lado;
}
```

- `extends` herda a implementação.
- `implements` só assina o contrato e você reescreve tudo. No Dart, **toda classe é também uma interface**.
- `super.metodo()` chama a versão da mãe.

O Flutter é feito assim: `class MeuWidget extends StatelessWidget`.

- for (var f in <Forma>[Retangulo(3, 4), Circulo(2)]) { print(f.descrever()); }

--- solution
import 'dart:math';

abstract class Forma {
  String get nome;
  double area();
  String descrever() => '$nome: ${area().toStringAsFixed(2)}';
}

class Retangulo extends Forma {
  final double largura, altura;
  Retangulo(this.largura, this.altura);
  @override
  String get nome => 'Retângulo';
  @override
  double area() => largura * altura;
}

class Circulo extends Forma {
  final double raio;
  Circulo(this.raio);
  @override
  String get nome => 'Círculo';
  @override
  double area() => pi * raio * raio;
}

void main() {
  for (var f in <Forma>[Retangulo(3, 4), Circulo(2)]) {
    print(f.descrever());
  }
}

=== mixins | 2 | dart | Mixins
--- lesson
Um **mixin** é um pacote de métodos que você "mistura" em várias classes, sem herança. É útil quando classes diferentes precisam do mesmo comportamento:

```dart
mixin Logavel {
  void log(String msg) => print('[${runtimeType}] $msg');
}

class Pagamento with Logavel {
  void pagar() => log('pago');
}
```

Uma classe pode usar **vários** mixins: `class X extends Y with A, B`.

No Flutter você verá `with SingleTickerProviderStateMixin` nas animações e `with ChangeNotifier` no gerenciamento de estado.

=== records | 2 | dart | Records e pattern matching
--- lesson
**Records** (Dart 3) agrupam valores sem precisar criar uma classe, e são ótimos para devolver **mais de um valor** de uma função:

```dart
(int, int) minMax(List<int> v) => (v.reduce(min), v.reduce(max));
```

=== async | 2 | dart | Future, async/await e Stream
--- lesson
Apps conversam com APIs e banco de dados, o que **demora**. O Dart usa **Future** para um valor que chega no futuro:

--- solution

  await Future.delayed(const Duration(milliseconds: 100));
  return nota;
}

Stream<int> contagem() async* {
  for (var i = 3; i >= 1; i--) {
    await Future.delayed(const Duration(milliseconds: 50));
    yield i;
  }
}

void main() async {

  print('Ana: $ana');

  var notas = await Future.wait([buscarNota('Bruno', 7.0), buscarNota('Carla', 9.5)]);
  print('Bruno: ${notas[0]}, Carla: ${notas[1]}');

  await for (var n in contagem()) {

const resposta = '[{"nome":"Ana","notas":[8,7.5,9]},{"nome":"Bruno","notas":[6,5.5,7]},{"nome":"Carla","notas":[9.5,9,10]}]';

class Aluno {
  final String nome;
  final List<double> notas;
  Aluno({required this.nome, required this.notas});

  factory Aluno.fromJson(Map<String, dynamic> j) => Aluno(
        nome: j['nome'] as String,
        notas: (j['notas'] as List).map((n) => (n as num).toDouble()).toList(),
      );

  double get media => notas.reduce((a, b) => a + b) / notas.length;

  Map<String, dynamic> toJson() => {'nome': nome, 'media': double.parse(media.toStringAsFixed(2))};
}

void main() {
  final alunos = (jsonDecode(resposta) as List).map((e) => Aluno.fromJson(e as Map<String, dynamic>)).toList();

  for (final a in alunos) {
    print('${a.nome}: ${a.media.toStringAsFixed(2)}');
  }

  final melhor = alunos.reduce((a, b) => a.media >= b.media ? a : b);
  print('Melhor: ${melhor.nome}');
  print(jsonEncode(melhor.toJson()));
}

--- solution
import 'package:flutter/material.dart';

void main() => runApp(MaterialApp(home: ListaAlunos(turma: Turma())));

class Aluno {
  final String nome;
  final List<double> notas = [];
  Aluno(this.nome);
  double get media => notas.isEmpty ? 0 : notas.reduce((a, b) => a + b) / notas.length;
}

class Turma extends ChangeNotifier {
  final List<Aluno> alunos = [Aluno('Ana')..notas.addAll([8, 9]), Aluno('Bruno')..notas.addAll([5, 6])];

  void adicionarAluno(String nome) {
    alunos.add(Aluno(nome));
    notifyListeners();
  }

  void adicionarNota(Aluno aluno, double nota) {
    aluno.notas.add(nota);
    notifyListeners();
  }
}

class ListaAlunos extends StatelessWidget {
  final Turma turma;
  const ListaAlunos({super.key, required this.turma});

  Future<void> _novoAluno(BuildContext context) async {
    final controller = TextEditingController();
    final nome = await showDialog<String>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Novo aluno'),
        content: TextField(controller: controller, decoration: const InputDecoration(labelText: 'Nome')),
        actions: [
          TextButton(onPressed: () => Navigator.pop(context), child: const Text('Cancelar')),
          ElevatedButton(onPressed: () => Navigator.pop(context, controller.text.trim()), child: const Text('Adicionar')),
        ],
      ),
    );
    if (nome != null && nome.isNotEmpty) turma.adicionarAluno(nome);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Notas da Turma')),
      body: ListenableBuilder(
        listenable: turma,
        builder: (context, _) => ListView(
          children: [
            for (final a in turma.alunos)
              ListTile(
                leading: Icon(a.media >= 6 ? Icons.check_circle : Icons.cancel, color: a.media >= 6 ? Colors.green : Colors.red),
                title: Text(a.nome),
                trailing: Text(a.media.toStringAsFixed(1)),
                onTap: () => Navigator.push(
                  context,
                  MaterialPageRoute(builder: (_) => DetalheAluno(turma: turma, aluno: a)),
                ),
              ),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(onPressed: () => _novoAluno(context), child: const Icon(Icons.add)),
    );
  }
}

class DetalheAluno extends StatefulWidget {
  final Turma turma;
  final Aluno aluno;
  const DetalheAluno({super.key, required this.turma, required this.aluno});

  @override
  State<DetalheAluno> createState() => _DetalheAlunoState();
}

class _DetalheAlunoState extends State<DetalheAluno> {
  final _controller = TextEditingController();
  String? _erro;

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  void _lancar() {
    final nota = double.tryParse(_controller.text.replaceAll(',', '.'));
    if (nota == null || nota < 0 || nota > 10) {
      setState(() => _erro = 'Nota deve ser de 0 a 10');
      return;
    }
    setState(() => _erro = null);
    widget.turma.adicionarNota(widget.aluno, nota);
    _controller.clear();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(widget.aluno.nome)),
      body: ListenableBuilder(
        listenable: widget.turma,
        builder: (context, _) => Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Média: ${widget.aluno.media.toStringAsFixed(1)}', style: const TextStyle(fontSize: 20)),
              const SizedBox(height: 8),
              Wrap(spacing: 6, children: [for (final n in widget.aluno.notas) Chip(label: Text(n.toString()))]),
              const SizedBox(height: 16),
              Row(
                children: [
                  Expanded(
                    child: TextField(
                      controller: _controller,
                      keyboardType: const TextInputType.numberWithOptions(decimal: true),
                      decoration: InputDecoration(labelText: 'Nova nota', errorText: _erro),
                    ),
                  ),
                  const SizedBox(width: 8),
                  ElevatedButton(onPressed: _lancar, child: const Text('Lançar')),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}
