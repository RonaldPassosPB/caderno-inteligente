=== java-ola | 1 | java | Olá, mundo!
--- lesson
Todo programa Java vive dentro de uma **classe**, e a execução começa no método **main**:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Bom dia!");
    }
}
```

- `System.out.println` mostra um texto e pula para a próxima linha.
- O texto vai entre **aspas duplas**, e toda instrução termina com **ponto e vírgula**.
- Java diferencia maiúsculas de minúsculas: `system.out.Println` não funciona.
- Por enquanto, encare `public static void main(String[] args)` como "o ponto de partida". Cada palavra vai fazer sentido ao longo da trilha.

Escreva um programa que mostre exatamente **Olá, mundo!** na tela.
--- reqs
- Tem a classe Main com o método main
- Usa System.out.println
--- hints
- Dentro do main, uma única linha com System.out.println.
- System.out.println("Olá, mundo!");
--- starter
public class Main {
    public static void main(String[] args) {

    }
}
--- solution
public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}

=== java-operadores | 1 | java | Operações matemáticas
--- lesson
Operadores: `+`, `-`, `*`, `/` e `%` (resto).

**Pegadinha clássica:** divisão entre dois `int` dá `int`, e a parte decimal é **descartada**:

```java
int x = 7, y = 2;
System.out.println(x / y);           // 3
System.out.println(x % y);           // 1
System.out.println((double) x / y);  // 3.5
```

`(double)` é um **cast**: converte o valor antes da conta.

Outra pegadinha: dentro de um texto, a conta precisa de parênteses. `"Soma: " + a + b` vira `"Soma: 175"` (junta os textos), enquanto `"Soma: " + (a + b)` dá `"Soma: 22"`.

- Divisão real: (double) a / b
--- starter

        int a = 17;
        int b = 5;

    }
}
--- solution
public class Main {
    public static void main(String[] args) {
        int a = 17;
        int b = 5;

        System.out.println("17 + 5 = " + (a + b));
        System.out.println("17 - 5 = " + (a - b));
        System.out.println("17 * 5 = " + (a * b));
        System.out.println("17 / 5 = " + (a / b));

=== java-format | 1 | java | Formatando com printf e String.format
--- lesson
Para controlar casas decimais e montar textos, use **printf** ou **String.format** com marcadores:

| Marcador | Para | Exemplo |
|---|---|---|
| `%s` | texto | `"Olá, %s"` |
| `%d` | inteiro | `"%d itens"` |
| `%.2f` | decimal com 2 casas | `"R$ %.2f"` |
| `%n` | quebra de linha | |

```java
String aluno = "Bruno";
double media = 8.25;
System.out.printf("%s tirou %.1f%n", aluno, media);   // Bruno tirou 8.3
String msg = String.format("Média: %.2f", media);      // "Média: 8.25"
```

**Atenção:** `%.2f` usa o idioma do computador. Num Windows em português sai vírgula (`8,25`). Aqui no treino vale o ponto (`8.25`).

Desde o Java 15 também dá para escrever `"Média: %.2f".formatted(media)`.

=== java-switch | 2 | java | switch clássico e switch moderno
--- lesson
O **switch clássico** precisa de `break`, senão "cai" no caso seguinte (fall-through):

```java
switch (opcao) {
    case 1:
        System.out.println("Cadastrar");
        break;
    default:
        System.out.println("Opção inválida");
}
```

Desde o Java 14, o **switch com seta** é mais seguro (não tem fall-through) e pode **devolver valor**:

```java
String texto = switch (opcao) {
    case 1 -> "Cadastrar";
    case 2, 3 -> "Listar";
    default -> "Opção inválida";
};
```
--- task

--- reqs
- Usa switch (clássico ou com seta)
- Tem um caso default para valores inválidos
--- hints
- int dia = Integer.parseInt(sc.nextLine());
- String nome = switch (dia) { case 1 -> "Domingo"; ... default -> "Dia inválido"; };
--- input
3
--- starter
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

    }
}
--- solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int dia = Integer.parseInt(sc.nextLine());
        String nome = switch (dia) {
            case 1 -> "Domingo";
            case 2 -> "Segunda-feira";
            case 3 -> "Terça-feira";
            case 4 -> "Quarta-feira";
            case 5 -> "Quinta-feira";
            case 6 -> "Sexta-feira";
            case 7 -> "Sábado";
            default -> "Dia inválido";
        };
        System.out.println(nome);
    }
}

=== java-while | 2 | java | Repetição com while e do-while

```java
int saldo = 100;
while (saldo > 0) {
```

```java
do {
```

=== java-continue | 2 | java | break e continue

```java
for (int i = 1; i <= 10; i++) {
```

=== java-arrays | 2 | java | Arrays e for-each
--- lesson
Um **array** tem tamanho fixo e guarda valores do mesmo tipo:

```java
int[] idades = {18, 22, 30};
System.out.println(idades[0]);       // 18 (índice começa em 0)
System.out.println(idades.length);   // 3 (sem parênteses!)

for (int idade : idades) {           // for-each: "para cada idade em idades"

}
```

Acessar um índice que não existe (`idades[3]`) lança **ArrayIndexOutOfBoundsException**.

Com **double[] notas = {7.5, 8.0, 6.5, 9.0, 5.5}**, mostre cada nota com 1 casa usando **for-each**, depois a **média** (2 casas) e a **maior nota** (1 casa), calculadas no laço, sem usar Streams.

- Calcula soma e maior valor manualmente (sem Streams nem Arrays.stream)

- double soma = 0, maior = notas[0]; for (double n : notas) { ... if (n > maior) maior = n; }
- System.out.printf("Média: %.2f%n", soma / notas.length);
--- starter
public class Main {
    public static void main(String[] args) {
        double[] notas = {7.5, 8.0, 6.5, 9.0, 5.5};

    }
}
--- solution
public class Main {
    public static void main(String[] args) {
        double[] notas = {7.5, 8.0, 6.5, 9.0, 5.5};
        double soma = 0;
        double maior = notas[0];

        for (double n : notas) {
            System.out.printf("Nota: %.1f%n", n);
            soma += n;
            if (n > maior) maior = n;
        }

        System.out.printf("Média: %.2f%n", soma / notas.length);
        System.out.printf("Maior: %.1f%n", maior);
    }
}

=== java-equals | 3 | java | == ou equals? (a pegadinha clássica)
--- lesson
Em Java, objetos são **referências**:

- `==` compara se é **o mesmo objeto na memória**;
- `.equals()` compara o **conteúdo**.

```java
String a = "java";
```

    public static void main(String[] args) {
        String primeiros = fibonacci().limit(10).map(String::valueOf).collect(Collectors.joining(", "));
        long soma = fibonacci().takeWhile(x -> x < 100).mapToLong(Long::longValue).sum();
        System.out.println("10 primeiros: " + primeiros);
        System.out.println("Soma dos menores que 100: " + soma);
    }
}

=== java-async | 4 | java | Programação assíncrona com CompletableFuture
--- lesson
Tarefas demoradas (rede, banco, arquivos) não devem travar o programa. O **CompletableFuture** roda trabalho em outra thread e junta os resultados depois:

```java
CompletableFuture<String> f = CompletableFuture.supplyAsync(() -> baixar("site.com"));
String resultado = f.join();          // espera o resultado

CompletableFuture<Integer> a = CompletableFuture.supplyAsync(() -> 2);
CompletableFuture<Integer> b = CompletableFuture.supplyAsync(() -> 3);
int soma = a.thenCombine(b, Integer::sum).join();   // as duas rodam em paralelo
```

- `supplyAsync` inicia a tarefa e devolve na hora; `join()` espera.
- `thenApply` transforma o resultado, e `thenCombine` junta dois.
- Imprima só **depois** do `join()`: assim a ordem da saída é sempre a mesma.

No Java 21 também existem as **virtual threads** (`Thread.ofVirtual()`), leves o bastante para milhares de tarefas ao mesmo tempo.

import java.util.concurrent.CompletableFuture;

public class Main {
    static double buscarNota(String aluno, double nota) {
        try {
            Thread.sleep(100);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        return nota;
    }

    public static void main(String[] args) {
        System.out.println("Buscando nota da Ana...");
        double ana = CompletableFuture.supplyAsync(() -> buscarNota("Ana", 8.5)).join();
        System.out.printf("Ana: %.1f%n", ana);

        System.out.println("Buscando Bruno e Carla em paralelo...");
        CompletableFuture<Double> bruno = CompletableFuture.supplyAsync(() -> buscarNota("Bruno", 7.0));
        CompletableFuture<Double> carla = CompletableFuture.supplyAsync(() -> buscarNota("Carla", 9.5));
        double media = bruno.thenCombine(carla, (b, c) -> (b + c) / 2).join();
        System.out.printf("Bruno: %.1f, Carla: %.1f%n", bruno.join(), carla.join());
        System.out.printf("Média dos dois: %.2f%n", media);
    }
}

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        Turma turma = new Turma();
        turma.adicionarNota("Ana", 8.5);
        turma.adicionarNota("Bruno", 5.5);
        turma.adicionarNota("Carla", 9.5);
        turma.adicionarNota("Diego", 7.5);

        try {
            turma.adicionarNota("Erro", 11);
        } catch (IllegalArgumentException e) {
            System.out.println("Nota inválida para Erro");
        }

        System.out.println("Ranking:");
        turma.ranking().forEach(System.out::println);
        System.out.printf("Média da turma: %.2f%n", turma.media());
        System.out.println("Aprovados: " + String.join(", ", turma.aprovados()));
    }
}

record Nota(String aluno, double valor) {}

class Turma {
    private final List<Nota> notas = new ArrayList<>();

    public void adicionarNota(String aluno, double valor) {
        if (valor < 0 || valor > 10) throw new IllegalArgumentException("Nota fora de 0 a 10: " + valor);
        notas.add(new Nota(aluno, valor));
    }

    public List<String> ranking() {
        List<Nota> ordenadas = notas.stream()
            .sorted(Comparator.comparingDouble(Nota::valor).reversed())
            .toList();
        return IntStream.range(0, ordenadas.size())
            .mapToObj(i -> String.format("%dº %s - %.1f", i + 1, ordenadas.get(i).aluno(), ordenadas.get(i).valor()))
            .toList();
    }

    public double media() {
        return notas.stream().mapToDouble(Nota::valor).average().orElse(0);
    }

    public List<String> aprovados() {
        return notas.stream().filter(n -> n.valor() >= 6).map(Nota::aluno).sorted().toList();
    }
}
